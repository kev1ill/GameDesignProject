# The Hick's Underworld

A 2D roguelite made in Godot for our game design class at Kalamazoo College.

You're a broke student who finds a secret dungeon under Hicks Center. Fight your way through it, beat the Guardians of Hicks, and get the legendary K-cash.

## How to run

1. Install [Godot](https://godotengine.org/download)
2. Clone this repo
3. Open Godot, click Import, and pick `project.godot`
4. Hit F5
